Premium packaging and manufacturing solutions website featuring modern 3D effects, smooth animations, and fully responsive design.

## 🌟 Features

### ✨ Modern Design
- **Premium 3D Effects** - Interactive card tilts and perspective transforms
- **Glassmorphism** - Frosted glass effect on cards and surfaces
- **Smooth Animations** - Scroll reveals, magnetic buttons, and parallax effects
- **Gradient Orbs** - Animated background elements with floating motion
- **Custom Typography** - Sora and Space Grotesk fonts for modern look

### 📱 Fully Responsive

Optimized for all device sizes with specific breakpoints:

| Device Type | Screen Size | Optimizations |
|-------------|-------------|---------------|
| **Extra Large** | 1440px+ | Expanded container, full visual effects |
| **Desktop** | 1024px - 1440px | Standard layout with all features |
| **Tablet** | 768px - 1024px | Single column layout, reorganized sections |
| **Mobile** | 480px - 768px | Mobile menu, stacked layout, optimized spacing |
| **Small Mobile** | 320px - 480px | Compact design, reduced font sizes, single column |
| **Landscape** | < 600px height | Horizontal optimized layout |

### 🎯 Touch Device Optimizations
- Disabled hover effects on touch devices
- Increased tap target sizes (minimum 44px)
- Removed 3D tilt effects on mobile for better performance
- Optimized animations for 60fps on all devices

### ⚡ Performance
- **RequestAnimationFrame** for smooth animations
- **Debounced scroll events** for better performance
- **Lazy loading** animations (Intersection Observer)
- **Conditional effects** based on device capabilities

### ♿ Accessibility
- Semantic HTML structure
- Proper heading hierarchy (H1-H4)
- ARIA labels for interactive elements
- Keyboard navigation support
- Focus states for all interactive elements
- `prefers-reduced-motion` support
- High contrast text colors (WCAG compliant)

## 🚀 Getting Started

### View Live
Visit the website at: `https://ashutosh0814.github.io/Rudra/`

### Run Locally

1. Clone the repository:
```bash
git clone https://github.com/ashutosh0814/Rudra.git
```

2. Navigate to the directory:
```bash
cd Rudra
```

3. Open `index.html` in your browser:
```bash
# On Windows
start index.html

# On macOS
open index.html

# On Linux
xdg-open index.html
```

Or use a local server:
```bash
# Python 3
python -m http.server 8000

# Node.js (with http-server)
npx http-server
```
